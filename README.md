Plaquette développée sous Kicad 9

Destinée à permettre l'expérimentation des ESP32, ESP32-S3, ESP32-C3 et Helltec CT62 (ESP32-C3+SX1262 (Lora)

Le systeme Flexypin peut permettre une vérification et programmation (par exemple pour implémenter l'OTA) avant soudure

Sur le PCB les pins sont indiquées Wroom=ESP32 puis S3 puis CT62.

Pour le CT62, les 2 pins du haut sont inutilisées
